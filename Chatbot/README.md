# Multimodal AI Chatbot

A beginner-friendly **Multimodal AI Chatbot MVP** built with React, FastAPI, Python and PostgreSQL.

## Local Setup

### 1. Backend

```bash
cd backend
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

For more details on the architecture, see the user request.
